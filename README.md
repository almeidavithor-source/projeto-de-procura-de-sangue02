# 🩸 VidaEmRede Pro - Sistema de Doação de Sangue

Plataforma Web modular para interligação de doadores voluntários, pacientes em casos emergenciais e hemocentros parceiros.

## 🚀 Diferenciais Técnicos

- **Mapa Geográfico:** Integração com LeafletJS e OpenStreetMap para exibição de hemocentros.
- **Banco de Dados Real:** Scripts PostgreSQL para integração direta via API com Supabase.
- **Calculadora de Compatibilidade:** Matriz interativa de receptores e doadores universais.
- **Pedidos Urgentes:** Sistema de publicação rápida de casos hospitalares graves.
- **Filtro Avançado:** Pesquisa combinada por UF, Cidade e Tipo Sanguíneo.

## 🛠️ Como Executar ou Fazer Deploy

1. Faça o fork/clone do repositório no seu GitHub.
2. Vá nas configurações do repositório no GitHub: **Settings** > **Pages**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve e acesse o link publicado!
